Schemes: `full` permutes every structure's labels; `local-w` permutes inside blocks of w consecutive positions; `sequences-k` scrambles k randomly chosen sequences completely and leaves the others intact. With zero conserved contacts in all n replicates of `full`, the empirical p value of the real count is below 1/(n + 1). The null tested here is relabelling positions within each structure; it does not test other nulls (unrelated proteins, a different alignment), and the oxidase rows use few replicates, so the sequences-k means depend on which groups the scrambled sequences fall in (a group of exactly five sequences has no tolerance).
